# 从第一份资料开始使用知页

## 一、知页能帮助你做什么

知页是一套围绕个人资料展开的学习工作台。你可以把课程讲义、研究笔记、项目文档放进同一个笔记本，再围绕这些来源提问、核对引用、整理学习材料。它适合解决“文件已经存好了，却很难再次找到关键内容”的问题。笔记本是一个主题空间，来源是放进这个空间的材料，对话和工作室则帮助你阅读与组织材料。建议一个课程、一个研究问题或一个项目使用一本笔记本，避免把互不相关的材料全部堆在一起。

知页的回答需要结合你选择的来源理解。资料没有提供某个结论时，应回到原文或补充资料，而不是把流畅的回答直接当成事实。页面上的引用让核对更方便，但引用标记本身不等于结论已经获得充分证明。学习者仍然需要判断原文是否支持回答中的每个关键判断。

## 二、用精选示例完成第一次体验

首页的“精选示例”提供四个已经准备好的主题：知页使用指南、大模型与 RAG 入门、毕业论文写作方法、高效学习方法。点击“立即体验”，系统会把对应示例复制到你的账户。来源、摘要、概要与已有向量一同复制，因此无需等待这些材料重新解析。模板正在准备时，按钮会提示稍后使用。

添加完成后进入工作台，先阅读概要和推荐问题，再查看左侧来源列表。可以尝试提问“上传资料后，怎样确认资料已经可以参与问答？”然后点击回答中的引用，核对对应原文。同一示例再次点击“打开”，会进入你已经添加的笔记本。复制后的内容属于你，可以上传新资料、改名或删除；这些操作不会影响官方模板和其他用户的副本。

## 三、准备适合阅读的来源

### 3.1 支持的材料类型

| 材料 | 使用方式 | 阅读前要知道 |
|---|---|---|
| PDF | 上传文字型 PDF | 扫描图片暂不支持 OCR |
| Word 与 Markdown | 上传文档或笔记 | 保留可提取的标题、正文等文字 |
| PPT | 上传演示文件 | 提取幻灯片文字、普通表格与备注 |
| Excel 与 CSV | 上传结构化资料 | 按工作表组织文字，存在行数上限 |
| 网页与文本 | 提供链接或直接粘贴 | 网页需要可公开访问并可提取正文 |

单个上传文件上限为二百兆字节，实际能否顺利使用还取决于正文规模和解析限制。新版 Office 文档可以直接解析；旧版 DOC、PPT、XLS 需要服务器安装 LibreOffice 进行转换。页面如果提示缺少转换工具，可先在本地另存为新版格式再上传。表格目前每张工作表最多读取前两千行数据，超出部分会在摘要中提示。不要依赖本系统完成复杂电子表格的公式计算或图表识别。

### 3.2 当前能力边界

音频和视频入口暂不自动转写。上传音频或添加视频链接时，系统保存的是说明性占位内容，不能据此回答真实节目中的观点。需要分析课程录音时，应先取得有权使用的转写文本或字幕，检查错误后作为文本来源加入。网页抓取不执行复杂脚本，也不能代替登录、验证码或付费访问流程。图片中的文字、幻灯片图形和扫描件需要先转换为可读文本。

## 四、观察来源处理状态

上传完成不代表资料已经可以检索。来源会依次经历上传、解析与整理，只有状态显示就绪，才适合加入问答。后台会提取正文、清洗、分块、生成向量，并生成来源摘要和主题。处理失败时，来源旁会显示中文原因。可以先确认文件能正常打开、含有可选择的文字、没有损坏，再根据提示重新添加。

建议第一次只上传一两份质量可靠的短资料。阅读来源摘要，检查主题是否符合预期，再展开正文预览。摘要只用于快速了解材料，不应替代原文。正文预览可能只展示开头部分；对于支持原件预览的文件，可以打开 PDF 预览或下载原件继续核对。上传前给文件取有意义的标题，也有助于随后识别引用。

## 五、组织自己的笔记本

首页支持按最近更新、创建时间和名称排序，也可以切换网格与列表。笔记本可以重命名，并使用标签分类。标签适合描述课程、学期或项目状态；同一本可以有多个标签。分类的目标是降低寻找成本，不需要为每份资料建立大量近义标签。比如“毕业设计”“待阅读”“方法论”可以分别描述项目归属、处理状态和材料性质。

整理时优先处理重复、过时或来源不明的材料。删除来源会移除它的检索分块，但已有回答可能仍保留引用摘录；失效引用无法再作为当前资料的可访问入口。删除笔记本则会清理其中的来源、对话、笔记和产物。操作前要确认重要原件已经另行保管，学习工作台不能代替个人文件备份。

## 六、一个十分钟上手流程

1. 在首页添加“知页使用指南”示例，阅读概要并确认两份来源均已就绪。
2. 只勾选其中一份来源，提出一个范围明确的问题，观察回答使用了哪些证据。
3. 再勾选另一份来源，询问两个环节之间的关系，比较引用变化。
4. 点击引用阅读原文，把核对后的要点保存为笔记，补上自己的理解。
5. 到工作室生成学习指南或思维导图，检查内容后继续编辑与学习。

这条流程覆盖资料、提问、引用和整理四个环节。每一步都应留下可核对的依据：来源是否正确，问题是否清楚，回答是否支持，笔记是否表达了你自己的理解。完成后再导入真实课程资料，会更容易判断系统在什么地方节省了时间、什么地方仍需要人工阅读。
