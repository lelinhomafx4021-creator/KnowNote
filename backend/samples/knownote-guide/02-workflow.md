# 带引用问答与工作室实践

## 一、把问题写成可以核对的任务

知页的问答围绕当前笔记本中已就绪、且被选中的来源展开。提问前先看左侧勾选状态，确保需要比较的材料都已选中。没有选择来源时，系统会提示先选择来源。一个有效问题通常包含对象、任务和范围。例如“根据这两份资料，比较来源摘要与笔记本概要的用途，并分别列出适合阅读的时机”，比“帮我分析一下”更容易获得清楚的答案。

问题不必很长，但最好一次聚焦一个学习目标。如果需要分析复杂主题，可以先问概念，再问条件，最后问应用。遇到模糊表达时，要补充课程语境，例如“这里的索引指数据库索引还是书籍索引”。让问题与资料中的标题、术语保持一致，有助于检索到相关段落。要求模型解释资料没有提到的细节时，应接受“资料不足”的回答，再决定是否补充来源。

## 二、理解回答是怎样得到的

后台先把问题转换为向量，再在选中来源的分块中检索相关片段，将这些片段与问题交给模型组织回答。检索只提供有限上下文，不表示每次都通读了所有原文。资料很长或问题涉及多个条件时，可以缩小问题范围、分别追问，再自己综合。标题、清晰段落和准确文本通常比堆积大量重复资料更有帮助。

页面以流式方式展示回答。生成过程中可以停止，已经出现的内容可能作为部分回答保留。部分回答没有完成论证，使用前需要特别核对。回答风格可在设置中调整为简洁、详细或学习模式；风格影响表达，不会自动增加来源中的事实。如果更换对话模型，也不意味着资料内容随之改变。

## 三、沿着引用回到证据

### 3.1 核对引用的三个问题

1. 引用来自你打算使用的那份材料吗？先核对来源标题。
2. 摘录是否支持回答中的具体说法？注意范围、前提、否定和例外。
3. 周围上下文是否改变了意思？必要时打开原件继续阅读。

PDF 引用可以带页码，幻灯片可以定位到第几张，表格可以显示工作表名称。Word 的章节标签描述语义结构，不能当作原始排版页码。文本和 Markdown 主要通过摘录核对。来源正文预览有长度限制，引用可能来自预览范围以外；此时仍可阅读引用片段或下载原件检查。

### 3.2 从回答走向个人理解

引用是一条检查路径，不能免除判断。回答中两个句子即使共用一个引用，也可能只有其中一句得到原文支持。发现不准确时，可以继续追问“请指出这个结论的原文依据”，也可以直接查看来源。点赞与点踩用于记录反馈，不会自动改写原文。保存回答为笔记后，建议加入自己的解释、疑问和待核实项，避免只收藏一段没有消化的生成文字。

## 四、选择合适的工作室产物

| 功能 | 适合的学习任务 | 使用后的检查 |
|---|---|---|
| 学习指南 | 整理知识点并用问题自测 | 先作答，再核对参考内容 |
| 简报文档 | 快速了解材料要点 | 检查重要前提是否被省略 |
| 常见问题 | 建立概念问答清单 | 合并重复问题，补足边界 |
| 时间线 | 梳理有日期的过程 | 资料无日期时不补造时间 |
| 思维导图 | 观察概念层次和联系 | 检查分支关系是否合理 |

这些内容以当前笔记本的就绪来源为基础生成。学习指南适合复习，简报适合预读，常见问题适合检查概念边界，导图适合建立全局结构。生成后应把产物当成待审阅的草稿：删去重复表述，补充你认为关键的证据，并回到来源验证。结构整齐不代表所有关系都正确。

音频概览会生成双主持人的对谈文稿。只有服务器配置语音合成能力时才会提供真实音频；否则可以阅读文稿。文稿长度与预计时长不等于已经生成可播放文件。语音功能的可用性取决于部署配置，不能仅凭页面出现“音频概览”就推断当前有真实音频服务。

## 五、把学习闭环落到笔记里

可以手动创建笔记，也可以从问答或工作室保存内容。推荐每条笔记围绕一个问题组织，包含“我的解释、原文依据、适用条件、还没弄懂的地方”。例如学习 RAG 时，不只记录流程，还应说明为什么更新资料后需要重建对应分块，以及检索命中为什么不能直接证明答案正确。这样的笔记可以用于复习与答辩，而不仅是展示阅读痕迹。

每次学习结束前，用三句话写下本次解决的问题、得到的主要结论和下一步要核对的内容。下一次进入笔记本，先尝试回忆这三句话，再阅读资料。知页提供组织与阅读工具，理解仍通过解释、练习和反馈逐步形成。保持少量高质量来源与清晰问题，通常更容易建立可维护的学习空间。

## 六、常见问题与处理顺序

### 来源一直在处理中怎么办

先等待片刻，再检查是否出现错误提示。大型文件、网页请求、模型服务繁忙都会影响处理时间。刷新页面可以重新观察后台状态，但重复上传会产生多份来源。如果持续失败，应根据错误原因检查文件或服务配置，避免无目的地反复提交。

### 为什么没有真实模型也能演示

未配置模型密钥时，系统使用 Fake 能力完成离线流程。它可以生成确定性的向量和基于材料摘录的示例回答，帮助体验上传、引用与工作室。Fake 的语义理解和整理质量有限，不能用于评价真实大模型的能力。模型配置、可用列表和额度由服务器决定，普通用户在设置中选择已开放的模型。

### 为什么提示额度已用完

对话、来源摘要、概要和工作室都可能消耗共享额度。后台摘要也是模型调用，不能只按手动提问次数估计用量。设置中可以查看今日请求与 Token 情况；Token 统计优先使用服务商返回值，缺失时采用估算。示例复制本身不调用模型，复制后继续提问或生成新产物则遵循当前用户的正常规则。
