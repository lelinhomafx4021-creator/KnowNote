# 知页 KnowNote 开发计划

基于大语言模型的个人资料管理系统（仿 NotebookLM）。用户上传论文、网页、文档等资料，系统解析并建立向量索引，支持带引用的智能问答、自动生成学习资料与思维导图。

## 技术选型

| 层 | 技术 |
|---|---|
| 前端 | React 18 + TypeScript + Vite + Tailwind CSS + zustand（`frontend/`，支持真实后端与 `VITE_USE_MOCK=true` 离线演示） |
| 后端 | Go + Gin + GORM（`backend/`） |
| 数据库 | PostgreSQL 16 + pgvector（Docker 启动，见 `docker-compose.yml`） |
| 大模型 | OpenAI 兼容接口（对话 / 向量化 / 可选 TTS），`base_url`、`api_key`、模型名均可配置；未配置密钥时使用内置 Fake 模型，保证可离线演示与测试 |
| 鉴权 | JWT（HS256，7 天有效）+ bcrypt 密码哈希，多用户数据隔离 |

## 系统架构

```
React SPA ──HTTP/SSE──▶ Gin 路由 ─▶ 中间件(CORS/日志/JWT)
                                   ├─ handler ─▶ service ─▶ GORM ─▶ PostgreSQL(+pgvector)
                                   │                     └─▶ llm(OpenAI 兼容 / Fake)
                                   └─ 后台任务: 来源解析 → 切分 → 向量化 → 摘要
```

RAG 问答流程：问题向量化 → 在选中来源的分块里做余弦 Top-K → 按编号拼接上下文 → 要求模型用 [n] 标注引用 → SSE 流式返回 citations / delta / done。

## 验收标准（总体）

1. `docker compose up -d` 启动数据库后，`backend` 与 `frontend` 各自一条命令启动。
2. 注册登录 → 新建笔记本 → 上传 PDF / 添加网页 → 来源变为 ready 并显示摘要。
3. 提问后流式返回回答，引用角标可跳转到来源原文。
4. 工作室能生成五种内容，笔记可增删改。
5. 未配置 API Key 时整套流程依然可跑通（Fake 模型）；配置后使用真实模型。
6. `go test ./...` 与 `npm run build` 通过。
