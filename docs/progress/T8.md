# T8 交付说明：多格式来源体验、原件预览与引用定位

状态：已完成。日期：2026-11-14。

## 完成内容

- 按最新接口契约补齐 `pptx/xlsx/csv` 类型、`SourceSection`、来源页数/目录/预览能力/原始扩展名，以及引用的 `page/locationLabel`。
- 上传入口支持 PDF、PPT/PPTX、DOC/DOCX、XLS/XLSX、CSV、TXT/Markdown 与既有音频格式。按扩展名将旧版 Office 映射到对应来源类型；多选和拖入共用逐文件校验与并发上传流程，保留大小限制、上传进度和解析状态。
- 增加橙色演示文稿图标、绿色表格图标；来源列表第二行显示类型与页数、幻灯片张数或工作表数。
- 来源详情采用现有 Material 3 变量色、柔和卡片、大圆角与细边框：头部展示标题、类型/大小/页数徽标、查看原件与下载；保留概览、主题、原文预览和引用高亮，新增带摘录的目录。
- 原件预览在桌面覆盖中间及右侧区域，保留左侧目录；手机全屏展示。支持目录跳页、页码输入、上一页/下一页、关闭、新标签打开和下载。真实地址由接口层生成，使用 `/api/sources/:id/preview?token=…#page=N` 与 `/file?token=…`，支持已有 API 基地址配置；链接和 iframe 不发送 Referer。
- 引用卡片显示位置标签。点击引用自动展开左栏、定位来源并高亮；可预览来源提供「在原件中查看第 N 页」按钮。保留「引用了 N 个来源」，手机下操作区可换行。
- 工作台保留引用位置与预览页码，关闭预览仍保留引用片段；切换来源、删除来源、切换笔记本或退出时清理相应预览状态。引用定位兼容后端折叠空白后的片段。
- mock 首个笔记本增加六张幻灯片的 PPTX、两个工作表的 XLSX；PDF 示例包含三页目录和预览。回答优先引用这些来源，分别演示 PDF 第 3 页、幻灯片第 4 张、工作表位置。`public/demo/` 提供与摘录对应的 3 页阅读指南和 6 张幻灯片 SVG，占位页面随容器缩放，可离线演示。
