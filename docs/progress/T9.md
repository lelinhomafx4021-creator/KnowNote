## 切换真实模型只需填写的变量

保持旧 `LLM_API_KEY` 为空，避免它回退到未配置的新能力；所有真实 Key 通过安全的环境注入方式提供。

| 变量 | 应填内容 |
|---|---|
| CHAT_BASE_URL | https://api.deepseek.com |
| CHAT_API_KEY | DeepSeek Key |
| CHAT_MODEL | deepseek-flash（该域名下不填也默认此模型） |
| CHAT_MODELS | 可选：deepseek-flash,deepseek-v4-pro，供设置切换 |
| EMBED_BASE_URL | https://你的业务空间ID.cn-beijing.maas.aliyuncs.com/compatible-mode/v1 |
| EMBED_API_KEY | 与地域匹配的百炼 Key |
| EMBED_MODEL | text-embedding-v4 |
| EMBEDDING_DIM | 默认1536，保持现有库一致；修改前必须重建 |

语音可选填写 TTS_BASE_URL、TTS_API_KEY、TTS_MODEL、TTS_VOICES（两个音色），未配置就只显示文稿。图像保留 IMAGE_PROVIDER/BASE_URL/API_KEY/MODEL，provider 留空关闭，不需要为本轮业务填写。已有资料更换向量模型，即使维度相同也必须先停服、导出目标配置、运行 scripts/reindex.sh，再重启；重建仍计入 Token，可仅对维护进程临时设置 QUOTA_DAILY_TOKENS=0。

配置依据：[DeepSeek 更新记录](https://api-docs.deepseek.com/updates/)、[JSON Output](https://api-docs.deepseek.com/guides/json_mode/)、[百炼向量接口](https://help.aliyun.com/zh/model-studio/text-embedding-synchronous-api/)、[兼容地址说明](https://help.aliyun.com/zh/model-studio/embedding-interfaces-compatible-with-openai)。Flash 当前对应较新的 V4.1 Flash，Pro 为继续提供的上一代 V4 Pro；本项目使用文本能力。v4 支持2048/1536/1024/768/512/256/128/64，最多10条/批、8192 Token/条；本项目 HNSW 上限2000维，示例选1536维，不支持2048维。官方另有 qwen3.7-text-embedding，此次采用 v4 作为兼容现有库的示例。

## 已知问题与边界

- 用量优先供应商usage，缺失按字符估算，不是精确账单。调用前预留输入+最大输出，余额低于请求预算会提前拒绝；异常退出超过五分钟的未结算预留，在该用户下次调用时按预算保守结算。失败与取消也记录，不保存提示词或回答。
- 每日次数和限速含摘要/概要/工作室的对话生成；向量和TTS只计Token。额度与速率以数据库共享，并发上限为单进程；后台队列仍沿用项目的单实例部署边界。
- 图像只开放内部接口；dashscope值预留OpenAI兼容模式，原生异步图像任务协议未实现。尚无图像业务表/界面/文件路由，后续开放时需补充配额、归属、删除清理。Fake PNG优先系统中文字体，没有中文字体时显示Unicode转义。
- 没有真实模型/TTS/OSS付费调用，本轮验证协议与流程，不声称真实模型质量或真实MP3播放效果。设置弹窗完成构建与接口验证，未追加浏览器视觉验收。
