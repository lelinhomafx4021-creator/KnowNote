## 完成内容与关键文件

- `backend/internal/model/relations.go`、`internal/db/db.go`：新增 tags、notebook_tags、message_citations、login_logs 四张业务表，以及 schema_migrations 运维表。标签同用户名称唯一；关联表联合主键，两端 CASCADE。引用从消息 CASCADE，来源/分块 SET NULL；用户删除级联已关联的成功认证日志。补齐复合外键完整索引、邮箱失败窗口和日志列表索引。
- `internal/service/tags.go`、`handler/tags.go`、`service/notebooks.go`：标签 CRUD、按标签过滤、笔记本返回 tags 数组、事务整体替换关联。批量装配标签，避免列表逐本查询；标签先按当前用户校验并加共享锁，非法/越权替换保留原关联，跨用户统一 404。CORS 增加 PUT。
- `internal/db/citations.go`、`service/chat`：一次性迁移旧 JSONB 引用，保存标题、摘录、位置与原来源标识；同用户同笔记本且仍存在的来源建立外键，旧数据无法可靠反推分块，chunk_id 留空。新回答与引用同事务保存，仅保存正文实际使用的编号；历史从引用表组装，原接口与 SSE 格式保持兼容。旧 JSONB 列保留，正常新消息排除其写入、使用空数组默认值。
- `internal/db/reindex.go`：向量重建过程中暂存并恢复引用的 chunk_id，避免原有“删除再恢复分块”触发 SET NULL 后永久丢失关联；扩充原有重建测试验证链接保留。
- `internal/service/login_logs.go`、`handler/auth.go`：注册/登录成功、错误密码、重复邮箱、参数错误和限流均记审计；不保存密码/token/请求体。失败 user_id 为空，记录规范化邮箱；数据库邮箱级事务锁串行化 10 分钟失败计数与认证写入，第六次起返回 429“尝试次数过多，请稍后再试”。GET /me/login-logs 返回当前用户及当前邮箱匿名失败记录的最近 20 条。
- `frontend/src/api`、`types/index.ts`、`features/home`、`pages/HomePage.tsx`：卡片底部彩色圆角标签、编辑标签弹窗（已有标签勾选、新建、颜色选择/修改、删除）、首页胶囊筛选；mock 同步 CRUD、过滤和整体替换。删除当前筛选标签会恢复“全部”，避免继续请求已删除标签。
- `components/layout/Overlays.tsx`：设置增加登录记录，显示时间、成功/失败、IP 和浏览器；日志加载失败有局部重试，不阻断模型设置。mock 记录演示认证成功。
- `docs/api.md`：同步标签、笔记本扩展、日志接口、认证限流语义和引用迁移说明。
- `docs/数据库设计.md`：全部 16 张表总体 Mermaid E-R 图，中文关系与 1:1/1:N/M:N 说明，20 条物理/概念关系说明，逐表数据字典（142 字段）、60 个索引（含 HNSW）、迁移与删除规则。字段类型、长度、可空、默认值和索引按实际迁移后的系统目录核对。`docs/架构设计.md` 的 ER 章节引用新文档，避免维护两个不同版本。

## 已知边界与未验证项

- 旧引用无分块 ID，迁移不会猜测，保留 source 外键和快照；新合并引用只关联组内原文第一块作为代表，具体规则已写入接口与数据库文档。
- 认证窗口内的成功不会清零失败次数，限流拒绝也记失败；失败日志保持匿名，正常删除用户只级联其成功日志。当前未增加审计日志自动保留期限。无法解析的请求保持原 400，同时记录可取得的邮箱；缺少邮箱时为空字符串。
- 本轮只用 Fake；未调用真实模型、TTS 或 OSS。原生颜色选择器的自定义改色未在浏览器完成操作，颜色校验/修改/持久化由后端集成测试及 mock API 验证覆盖。没有扩展为移动端全流程视觉回归。
- 正式部署应在旧版写入进程退出后完成 T10 迁移并启动新版本；运行旧代码的进程仍可能继续向旧 JSONB 写入，本轮按要求保留了既有演示进程。迁移版本保证一次执行，不提供多版本并行写入协议；保留的旧列可用于核查。
