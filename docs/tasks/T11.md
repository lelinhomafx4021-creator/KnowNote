【KnowNote T11】管理员后台：在平台内配置模型、存储与额度

你是 KnowNote 项目的全栈工程师，负责任务 T11。先完整阅读 `AGENTS.md`、`docs/api.md`、`docs/数据库设计.md`、`docs/progress/` 下全部交付说明（尤其 T7、T9、T10），以及 `backend/internal/config`、`internal/llm`、`internal/storage`。可修改 `backend/`、`frontend/`、`docs/`。

## 背景
目前模型（对话/向量/语音/图像）、存储（本地/阿里云 OSS）、额度等配置全部来自 `backend/.env`，改配置要改文件并重启。系统会给很多人使用，需要管理员在平台里自行更换。要求：`.env` 中的值作为**默认值**继续有效；管理员在后台保存的值覆盖默认值并**热更新**（无需重启）。

## 必须完成
1. **角色**：`users` 增加 `role`（`user` | `admin`）。第一个注册的用户自动成为管理员；另提供环境变量 `ADMIN_EMAILS`（逗号分隔）指定管理员。JWT 中带角色，新增管理员中间件。
2. **系统配置表** `system_settings`（key 主键、value、is_secret、updated_by FK→users、updated_at），以及配置读取层：数据库值 > `.env` 值 > 内置默认；保存后通知各模块重建客户端（对话、向量、TTS、图像、存储），正在进行的请求不受影响。
3. **密钥安全**：is_secret 的值（各类 API Key、OSS AccessKey Secret）用服务端主密钥 `SETTINGS_ENCRYPTION_KEY`（未设置时由 JWT_SECRET 派生）做 AES-GCM 加密存储；接口永远不回传明文，只显示 `sk-****e12a` 形式的掩码；留空提交表示不修改。
4. **接口**（写入 `docs/api.md`）：`GET /api/admin/settings`（分组返回，密钥打码，标明每项来源：数据库 / 环境变量 / 默认）、`PATCH /api/admin/settings`、`POST /api/admin/settings/test`（测试对话 / 向量 / OSS 连接，返回耗时与错误信息，不泄露密钥）、`GET /api/admin/users`（列表、用量、禁用/启用、设为管理员）、`GET /api/admin/usage`（按日、按用户、按模型的调用量与 token 统计）。修改向量模型或维度时提示需要重建向量，并提供“重建全部向量”按钮（调用 T9 的重建逻辑，后台任务 + 进度）。
5. **前端管理后台** `/admin`（仅管理员可见，用户菜单里增加入口）：NotebookLM / Material 3 风格，左侧分组导航：模型配置（对话 / 向量 / 语音 / 图像，含“测试连接”）、存储（本地 / OSS）、额度与限流、用户管理、用量统计（简单图表）。
6. **审计**：所有配置修改写入 `audit_logs`（id、user_id FK、action、target、detail 已脱敏、created_at），后台可查看最近记录。
7. **数据库设计文档**：把 role、system_settings、audit_logs 补进 `docs/数据库设计.md` 的 E-R 图与数据字典。
8. **测试**：配置优先级、热更新、加解密与掩码、管理员鉴权、普通用户访问 403、测试连接用 httptest 模拟。
