【KnowNote T8】前端：PPT/PDF/Office 来源体验、原件预览与引用定位

你是 KnowNote 项目的前端工程师，负责任务 T8。先完整阅读 `AGENTS.md`、`docs/api.md`（**“数据模型”中的 Source / SourceSection / Citation 与“来源”一节刚更新，是本任务的契约**）、`docs/progress/` 下全部交付说明，以及 `frontend/` 现有代码。只改 `frontend/` 和 `docs/`。另一个 Codex 对话（T7）正在并行实现后端，不要碰 `backend/`；git 提交只 add 你改的路径。

## 设计要求
界面刚改成 **NotebookLM / Material 3 风格**（见 `src/index.css` 的颜色变量、`src/pages/HomePage.tsx`、`src/pages/AuthPage.tsx`、`src/features/home/NotebookCard.tsx`）。新增和修改的界面必须沿用这套风格：Google 蓝主色、柔和底色、大圆角、细边框、中文文案、深浅色都好看。不要改动首页和登录页的整体设计。

## 必须完成
1. **类型**：按契约更新 `src/types/index.ts`（新增 SourceType：pptx/xlsx/csv；Source 新字段；SourceSection；Citation 的 page/locationLabel）。
2. **上传**：`AddSourceModal` 的 accept、格式标签与说明加入 PPT/PPTX、XLS/XLSX、CSV、DOC；`detectType` 按扩展名映射（ppt→pptx、doc→docx、xls→xlsx）；支持一次拖入多个文件。
3. **来源图标**：`SourceIcon` 增加 pptx（橙色，演示文稿图标）、xlsx/csv（绿色，表格图标）；`sourceTypeLabel` 对应“演示文稿”“表格”。
4. **来源详情（左栏 SourceDetail）**重做为 NotebookLM 式：
   - 头部：图标、标题、类型/大小/页数徽标；按钮“查看原件”（previewable 时）与“下载”。
   - “来源概览”卡片保留。
   - 新增“目录”：按 sections 列出“第 N 页 / 第 N 张幻灯片：标题 / 工作表：名称”与摘要，点击即在预览中跳到该页。
   - 原文预览保留，引用片段高亮保留。
5. **原件预览**：做一个 `SourcePreview` 组件——桌面端在工作台中间区域以覆盖层（或可调宽度的大面板）打开，移动端全屏；用 `<iframe src="/api/sources/:id/preview?token=…#page=N">` 显示 PDF，顶部有标题、当前页、关闭、在新标签打开、下载。mock 模式用 `public/` 下一个小示例 PDF（自己生成一个 2~3 页的中文说明 PDF，或用 SVG 占位页面）以便离线演示。
6. **引用定位**：`CitationChip` 悬停卡片显示 `locationLabel`（如“第 3 页”）；点击时打开左栏来源详情并高亮，同时若 previewable 则提供“在原件中查看第 N 页”按钮直接打开预览到该页。消息下方“引用了 N 个来源”保持。
7. **mock 数据**：为 mock 增加一个 PPTX 来源（带 6 张幻灯片的 sections）、一个 PDF 来源（带 pageCount/sections/previewable）、一个 XLSX 来源；mock 回答的 citations 带 page/locationLabel，保证离线演示能看到完整效果。
8. **列表**：来源列表项第二行显示简短信息（如“PDF · 12 页”“演示文稿 · 18 张”），处理中仍显示进度条。
