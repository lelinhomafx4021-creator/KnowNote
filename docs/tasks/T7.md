## 约束
- **不允许安装任何系统软件**（不用 brew，不装 poppler/tesseract），不做 OCR。
- 本机已有 LibreOffice：`/Applications/LibreOffice.app/Contents/MacOS/soffice`（不在 PATH）。新增配置 `SOFFICE_PATH`，未设置时依次查找 PATH 里的 `soffice`/`libreoffice` 与上述 macOS 路径；找不到时旧版格式按契约返回友好错误，其余功能不受影响。调用时用独立的临时 `-env:UserInstallation=file:///...` 目录、`--headless --convert-to`、超时 120s、并发上限 2，避免与用户打开的 LibreOffice 冲突。
- 新增 Go 依赖要纯 Go（不要 CGO）。

## 必须完成
1. **PDF**：按页提取文字，质量明显优于现在。优先评估 `github.com/klippa-app/go-pdfium` 的 WebAssembly 模式（纯 Go，无需 CGO），效果好就用它；不合适再改进现有 `ledongthuc/pdf` 的逐页提取（处理字间距、断行、页眉页脚重复行、连字符）。在进度文件里写明选择理由与对比结果。记录 pageCount。
2. **PPTX**（`archive/zip` + XML 自行解析即可）：按 `ppt/presentation.xml` 的幻灯片顺序，提取每张的标题（title/ctrTitle 占位符）、正文段落（保留项目符号层级为缩进列表）、表格（转 Markdown 表格）、演讲者备注（`notesSlides`，标注“备注：”）。每张幻灯片一个 section。
3. **DOCX 增强**：识别 Heading 样式转 Markdown 标题，表格转 Markdown 表格，列表保留；按标题切 section（无标题时整篇一个 section）。
4. **XLSX / CSV**：xlsx 用 `github.com/xuri/excelize/v2`；csv 自动识别 UTF-8/GBK 与分隔符。每个工作表一个 section，首行作为列名，按行输出“列名：值；列名：值”，单表最多 2000 行。
5. **旧版格式**：`.doc/.ppt/.xls` 先用 LibreOffice 转成 docx/pptx/xlsx 再走上面的解析器；`type` 与 `originalExt` 按契约设置。
6. **预览 PDF**：pdf 直接用原件；doc/docx/ppt/pptx 在解析成功后用 LibreOffice 转 PDF 存为 `preview.pdf`（失败不影响来源 ready，只是 previewable=false 并记日志）。实现 `GET /api/sources/:id/preview` 与 `GET /api/sources/:id/file`（鉴权、`?token=`、Range、归属校验）。
7. **分块带页码**：`chunks` 增加 `page`（int，可空）列（AutoMigrate 增量，老数据为空不报错）；切分不跨 section；`sources` 增加 `page_count`、`sections`（jsonb）、`previewable`、`original_ext`、`preview_key`/`object_key` 等需要的列。返回的 Source 带 `pageCount`、`sections`、`previewable`、`originalExt`。
8. **引用定位**：chat 的 citations 增加 `page` 与 `locationLabel`（PDF“第 N 页”、PPT“第 N 张幻灯片”、表格“工作表：名称”），并在提示词里给每段资料标注位置，便于模型说明出处；消息落库时一并保存。
9. **阿里云 OSS 存储**：把 `internal/storage` 抽象为接口（Put / Open / Delete / DeletePrefix / Stat / SignedURL(ctx,key,ttl)），实现 `local`（现有逻辑迁移）与 `oss`（官方 `github.com/aliyun/alibabacloud-oss-go-sdk-v2`）。按 `STORAGE_DRIVER` 选择，配置项与对象键严格按 api.md“文件存储”。解析时需要本地文件的步骤（LibreOffice、pdf 解析）先下载到临时目录，用完删除。上传原件、preview.pdf、音频概览（T4 的 mp3）全部走存储接口；local 模式下现有本地数据保持可读。OSS 模式下 preview/file/audio 接口 302 到 10 分钟签名 URL。删除来源/笔记本时清理对应对象。启动日志打印当前存储驱动（不打印密钥）。
10. **配置**：`backend/.env.example` 加上 `SOFFICE_PATH`、`STORAGE_DRIVER`、全部 `OSS_*`（值留空，写中文注释）；`scripts/dev.sh` 里从 `backend/.env` 读取的变量白名单加入 `SOFFICE_PATH`、`STORAGE_DRIVER`、`OSS_[A-Z_]+`（保持“只按 KEY=VALUE 解析、不执行文件”的写法）。`backend/README.md` 增加 OSS 配置说明（创建私有 Bucket、RAM 子账号最小权限、跨域无需配置因为走后端签名）。
11. **测试**：用 Go 代码在测试里**现场生成**样例文件（PPTX/DOCX/XLSX 可直接拼 zip+XML；PDF 可用纯 Go 库生成含中英文的多页 PDF），覆盖：PDF 逐页 section 与页码、PPTX 标题/正文/表格/备注、DOCX 标题与表格、XLSX 多工作表、CSV GBK、切分不跨页、citation 带 page。OSS 驱动用 `httptest` 模拟最小 OSS 接口（Put/Get/Delete/List）或 SDK 可注入的 transport 做单元测试；真实 OSS 无密钥时跳过。LibreOffice 相关测试在找不到 soffice 时 Skip。
