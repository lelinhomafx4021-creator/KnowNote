【KnowNote T1】Go 后端骨架：配置、数据库、JWT 登录、笔记本 CRUD、LLM 客户端

你是 KnowNote 项目的后端工程师，负责任务 T1。先完整阅读 `AGENTS.md`、`docs/api.md`、`docs/开发计划.md`、`frontend/src/types/index.ts`，严格遵守其中约定。只改 `backend/` 和 `docs/`（进度文件、计划表状态）。

## 目标
在 `backend/` 建立可运行、结构清晰、方便后续任务扩展的 Go 后端骨架（Go 1.27，module 名 `knownote`）。

## 必须完成
1. **配置** `internal/config`：从环境变量读取（可选加载 `backend/.env`，用 github.com/joho/godotenv），并提供 `backend/.env.example`，至少包含：
   `PORT=8080`、`DATABASE_URL=postgres://knownote:knownote@localhost:5432/knownote?sslmode=disable`、`JWT_SECRET=`、`DATA_DIR=./data`、
   `LLM_BASE_URL=https://api.openai.com/v1`、`LLM_API_KEY=`、`LLM_CHAT_MODEL=gpt-4o-mini`、`LLM_EMBED_MODEL=text-embedding-3-small`、`EMBEDDING_DIM=1536`、`LLM_TTS_MODEL=`、`LLM_TTS_VOICES=alloy,echo`、`CORS_ORIGINS=http://localhost:5173`。
   JWT_SECRET 为空时在开发模式自动生成并打印警告。
2. **数据库** `internal/db`：GORM 连接 Postgres；启动时 `CREATE EXTENSION IF NOT EXISTS vector`，AutoMigrate 全部模型。**一次性把后续任务要用的表都建好**，避免后面改表：
   users、user_settings、notebooks、sources、chunks（`embedding vector(EMBEDDING_DIM)`，用 pgvector-go 类型，并建 HNSW cosine 索引；含 source_id、notebook_id、user_id、chunk_index、content、token_count）、messages（citations 用 jsonb）、notes、artifacts（mindmap 用 jsonb）、audio_overviews、notebook_guides（缓存 summary 与 suggested_questions jsonb，带 stale 标记）。
   主键 UUID；外键/删除级联合理；常用查询字段加索引。
3. **统一响应** `pkg/response` 与错误码（见 AGENTS.md），以及 `handler` 层的参数绑定/校验工具函数。
4. **中间件**：CORS（按 CORS_ORIGINS）、请求日志（slog）、Recover、JWT 鉴权（把 userID 放进 gin.Context；同时支持 `?token=` 以便后续音频播放）。
5. **认证与用户**：`POST /api/auth/register`、`POST /api/auth/login`、`GET /api/me`、`GET/PATCH /api/me/settings`（storageUsed 按该用户 sources 的 size 求和，storageTotal 固定 5GB）。bcrypt 存密码，JWT HS256 有效期 7 天。注册时创建默认设置。
6. **笔记本 CRUD**：`/api/notebooks` 全套（见 api.md），sourceCount 实时统计；DELETE 级联删除相关数据（文件删除留给 T2 的 storage，先预留接口）。
7. **健康检查** `GET /api/health`（检测数据库）。
8. **LLM 客户端** `internal/llm`：定义接口
   ```go
   type Client interface {
       Chat(ctx, messages []Message, opts ChatOptions) (string, error)
       ChatStream(ctx, messages []Message, opts ChatOptions, onDelta func(string) error) (string, error)
       Embed(ctx, texts []string) ([][]float32, error)   // 内部按 64 条分批
       TTS(ctx, text, voice string) ([]byte, error)       // 未配置 TTS 模型时返回 ErrNotConfigured
       Name() string
   }
   ```
   - OpenAI 兼容实现（github.com/sashabaranov/go-openai，可配置 BaseURL），带超时与有限重试。
   - **Fake 实现**（LLM_API_KEY 为空时自动启用，启动日志说明）：Embed 用确定性哈希向量（维度=EMBEDDING_DIM，已归一化，相同文本相同向量、含相同词的文本相似度更高）；Chat/ChatStream 返回基于输入上下文拼出的合理中文回答（若消息里有编号资料 [1][2]，回答中要带这些引用标记），流式逐字输出。目的是没有密钥也能完整演示和测试。
9. **服务入口** `cmd/server/main.go`：组装依赖、注册路由（为 T2~T4 的路由留出清晰的注册位置，比如 `router.go` 里分组）、优雅关闭。
10. **测试**：config、response、JWT、Fake LLM（向量确定性与维度、流式输出）单元测试；认证 + 笔记本 CRUD 的集成测试（用真实数据库，`DATABASE_URL` 不可用时 Skip；测试数据用随机邮箱，结束后清理）。
11. **Makefile 或说明**：`backend/README.md` 写清启动方式（`docker compose up -d` → `cp .env.example .env` → `go run ./cmd/server`）。
