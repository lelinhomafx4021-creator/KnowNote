## 4. 性能简测

目的：确认本地小样本的入库和检索链路没有明显阻塞，为论文提供可复现的实测值。所有结果均为单机、低并发、Fake下的简测，不是容量、召回率或生产SLA测试。

### 4.1 入库耗时

后台处理取同一浏览器验收笔记本中 `sources.updated_at - sources.created_at`，在来源刚 ready、未重命名时查询，包含排队、提取、切分、Fake向量化、写块、摘要和最终状态更新。各类型一次样本：

| 来源 | 非空白字符数 | 后台处理耗时 |
|---|---:|---:|
| PDF（文字层） | 76 | 41.977 ms |
| 网页（example.com） | 132 | 236.658 ms |
| 中文文本 | 146 | 16.771 ms |

另以最终 `test:e2e` 样本测量“提交来源到前端轮询观察到ready”的墙钟耗时：

| 来源 | 非空白字符数 | 前端观测总耗时 |
|---|---:|---:|
| PDF | 61 | 1514 ms |
| 网页 | 132 | 1519 ms |
| 中文文本 | 2052 | 1527 ms |

两组样本大小不同，测量口径也不同，不可直接相减。前端固定1.5秒轮询，因而用户观察耗时受轮询分辨率影响，不能误当作实际数据库写入耗时。后台时间查询可复现为：

```sql
SELECT type, word_count,
       EXTRACT(EPOCH FROM (updated_at - created_at)) * 1000 AS processing_ms
FROM sources
WHERE user_id = '<测试用户UUID>' AND notebook_id = '<测试笔记本UUID>'
ORDER BY created_at;
```

### 4.2 向量检索耗时

在浏览器验收笔记本的三个ready来源、三个1536维分块上，以其中一个已存向量作为固定查询向量，用 `EXPLAIN (ANALYZE, FORMAT JSON)` 执行与 `rag/retriever.go` 相同的连接、user_id/notebook_id/sourceIds/ready约束、余弦排序与Top-6，独立执行十次，读取 PostgreSQL `Execution Time`：

| 指标 | 结果 |
|---|---:|
| 十次执行时间（ms） | 0.105、0.148、0.073、0.088、0.075、0.077、0.075、0.071、0.073、0.073 |
| 均值 | 0.086 ms |
| 最小 / 最大 | 0.071 / 0.148 ms |

此值不含客户端网络、连接建立、SQL规划和问题向量化。数据量极小，不能据此推断HNSW性能优势；没有强制索引或关闭顺序扫描，也没有大型语料与并发压测。

### 4.3 问答流式观测

最终脚本对“为什么毕设用 pgvector？”实际测得：从发送到接收有效citations约10 ms，到首个delta约10 ms，完成约880 ms，工作台收到246次内容变化。该口径包含HTTP/Vite代理、鉴权、问题保存、Fake向量化、检索及事件构造，不是纯SQL耗时。Fake故意逐字延迟便于演示取消，因此整段耗时不能代表真实模型推理速度。

## 5. 本轮修复与遗留结论

| 问题 | 处理结果 |
|---|---|
| 0.2阈值导致全空上下文 | 最高三块兜底、警告日志，补单元及SSE落库回归 |
| Fake主题出现数字和跨词碎片 | 中文词表最长匹配、自然短词、英文词频与停用词，补回归 |
| 视频入口宣称已能转写 | 改为当前支持链接、需手动粘贴字幕；DOC转换提示同步 |
| 百炼批量上限低于64条 | text-embedding-v系列每批最多10条；本地HTTP模拟验证 |
| 原T5缺少T3/T4真实接口联调 | 本轮全部真实调用，页面引用/笔记/工作室/文稿补查完成 |
| 非默认前端端口CORS | dev.sh同步默认来源并严格端口启动；5176实测通过 |
| 历史分任务文档过时 | 根README与子目录README更新，旧进度保留历史，T6集中逐条关闭/说明 |

真实付费Chat/Embedding/TTS未调用：本次无可用于验收的供应商凭据与真实MP3样本，也不读取用户密钥文件。模拟服务验证协议和控制流程，不能证明供应商当前全部参数兼容、真实语义质量或浏览器MP3解码/拖动/倍速表现。音频时长仍按文本估计，MP3采用顺序拼接，不转码。

OCR、DOC转换、音视频转写、动态/登录/反爬网页、分布式任务抢占和事务outbox未实现：这些需要额外引擎、外部服务或部署架构，当前毕业设计按既有单进程能力交付。readability依赖虽被上游弃用，但任务指定且现有安全/解析测试通过，本轮未更换解析器。摘要仅取前12000字，Fake领域词表与启发式代表片段仍有覆盖限制，思维导图Fake最多64个来源分支。错误来源需删除后重加，网络中断后的来源观察可刷新恢复；没有用户删除、JWT即时撤销、强制存储配额或真实模型质量评价能力。
